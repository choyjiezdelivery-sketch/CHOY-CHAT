# CHOY-CHAT Roadmap

A rough order of work. Nothing here is a commitment — it is a direction.

## Phase 1 — Foundations (current)

- [x] Repository scaffold, README, license, contributing guide
- [x] Express API with health, users and posts endpoints
- [x] Static web client that reads and writes posts
- [ ] Replace the in-memory store with a real database
- [ ] Input validation and consistent error responses

## Phase 2 — Accounts

- [ ] Sign up / sign in with hashed passwords
- [ ] Session or JWT authentication
- [ ] Profile page: avatar, bio, join date
- [ ] Edit and delete your own posts

## Phase 3 — Social graph

- [ ] Follow / unfollow
- [ ] Followers and following lists
- [ ] Feed filtered to people you follow
- [ ] Likes and comments with counts

## Phase 4 — Chat

- [ ] Direct messages between two users
- [ ] Real-time delivery over WebSockets
- [ ] Unread badges and read receipts

## Phase 5 — Polish

- [ ] Notifications for likes, comments, follows, mentions
- [ ] Image uploads with size and type limits
- [ ] Search across users and posts
- [ ] Rate limiting, logging, and automated tests
- [ ] Deployment pipeline and staging environment

## Ideas parking lot

- Stories / ephemeral posts
- Group chats
- Dark and light themes
- Mobile app shell
